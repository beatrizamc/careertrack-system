**Sistema de Gerenciamento de Candidaturas e Processos Seletivos**

Aplicação desenvolvida em Java com o objetivo de simplificar e organizar o gerenciamento de candidaturas a vagas de emprego.

O sistema permite que candidatos acompanhem suas oportunidades profissionais, registrem candidaturas e monitorem o andamento dos processos seletivos em um único ambiente, proporcionando maior organização e controle sobre sua trajetória profissional.

O projeto foi desenvolvido como parte da disciplina de **Programação Orientada a Objetos (POO)**, aplicando conceitos fundamentais de desenvolvimento e engenharia de software.

## Objetivos do Projeto

- Desenvolver uma solução para um problema real relacionado à organização de candidaturas profissionais.
- Facilitar o acompanhamento de processos seletivos e oportunidades de emprego.
- Aplicar conceitos de Engenharia de Software durante a estruturação e implementação do sistema.
- Desenvolver habilidades práticas em Java e Programação Orientada a Objetos.
- Exercitar a organização, modularização e manutenção de código.

## Funcionalidades

- **Cadastro de candidaturas:** registro de novas candidaturas vinculadas às vagas disponíveis.
- **Listagem:** visualização das candidaturas cadastradas.
- **Atualização:** alteração das informações e do andamento das candidaturas.
- **Exclusão:** remoção de candidaturas registradas.
- **Gerenciamento de vagas:** visualização das oportunidades previamente cadastradas.
- **Acompanhamento de status:** identificação da etapa atual de cada processo seletivo.

## Tecnologias Utilizadas

- **Java:** linguagem de programação utilizada no desenvolvimento.
- **Java Collections Framework:** utilização de `ArrayList` para armazenamento e gerenciamento de dados em memória.
- **Programação Orientada a Objetos:** estruturação do sistema utilizando classes, objetos e relacionamentos entre entidades.
- **Terminal / Console:** interface textual para interação com o usuário.
